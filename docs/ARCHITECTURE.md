# معمارية SHOPNEX

## المكونات

- **Tauri v2:** غلاف سطح المكتب بصلاحيات WebView أساسية محدودة وCSP مقيدة. لا تُمنح الواجهة صلاحيات نظام ملفات عامة.
- **React + TypeScript + Vite:** واجهة عربية RTL، قابلة للتبديل إلى LTR، ونظام تصميم كوني عالي التباين.
- **FastAPI:** API محلية مربوطة على `127.0.0.1`، مسارات versioned وعقود Pydantic وOpenAPI.
- **SQLAlchemy + Alembic:** نماذج الأعمال وترحيلات قاعدة البيانات الحتمية.
- **PostgreSQL محلي:** مصدر بيانات الأعمال المقصود، مع تشغيل التطوير الحالي على SQLite عند عدم توفر خادم محلي.

## حدود الثقة

لا يُوثق بأي مصدر خارجي أو اتصال تكامل افتراضي. يقبل API Origins المعروفة للتطوير وTauri فقط. لا يُربط الخادم افتراضيًا على `0.0.0.0`. لا تحتوي الواجهة على مفاتيح، ويجب ألا تطلب أسرارًا في التخزين المحلي للمتصفح. قيم الاعتماد تمر على الخادم المحلي إلى خزنة النظام، وتُعرض للواجهة كحالة وجود فقط.

## نطاق البيانات

العملة الأساسية SAR. تبدأ نماذج الشركة والمنتج والفاتورة ووثيقة ZATCA بعزل الشركة في قاعدة البيانات. النسخة الحالية تُجهّز أساسًا محليًا وليست بعدُ نظام محاسبة إنتاجيًا؛ يجب تطوير مصادقة المستخدمين والصلاحيات الدقيقة وترحيل المخزون والقيود المالية والمراجعة قبل استخدام سجلات فعلية.

## التشغيل والصيانة

- PostgreSQL فقط ضمن Docker Compose مع منفذ localhost وvolume محلي دائم؛ FastAPI تعمل على المضيف وبمنفذ loopback كي تتصل بخزنة أسرار نظام التشغيل.
- يدير Alembic تغييرات المخطط؛ لا تُنفذ عمليات DDL مدمرة أو ترحيلات غير مراجعة.
- لا تُخزّن أسرار التكامل في قاعدة البيانات أو سجل الأخطاء.
- لا توجد قاعدة سحابية أو مزامنة خارجية مفترضة.
