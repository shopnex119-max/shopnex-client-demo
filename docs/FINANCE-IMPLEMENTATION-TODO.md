# المشتريات والمحاسبة والتحليلات وQR — سجل التنفيذ

## أُنجز واختُبر في هذه الدفعة

- [x] إنشاء موردين وفواتير مشتريات مسجلة مع تفاصيل البنود والخصم والضريبة والدفعات وتاريخ الاستحقاق.
- [x] استقبال كامل للمخزون، سجل حركة مرتبط بالمستخدم/الفاتورة، وتحديث متوسط التكلفة المرجّح ضمن المعاملة نفسها.
- [x] دفعات مورد جزئية/كاملة، رفض الزيادة على الرصيد، ترحيل قيد الدفع، وidempotency يمنع التكرار أو اختلاف الحمولة عند إعادة المفتاح.
- [x] دليل حسابات أولي وقيود مزدوجة متوازنة للبيع/الشراء/السداد والرصيد الافتتاحي؛ ميزان مراجعة وأستاذ وذمم.
- [x] قواعد VAT مؤرخة بإصدارات ولقطات على البنود، تصنيف قياسي/صفري/معفى/خارج النطاق، وأسباب عند اشتراطها.
- [x] تقارير للفترة بعملة SAR وتوقيت Asia/Riyadh: المبيعات والمشتريات والذمم وVAT التقديري والمدفوعات والتكلفة والهامش الإجمالي والمخزون واتجاه اليوم وتحليل المنتجات والموردين.
- [x] تصدير CSV عربي UTF-8 BOM مع تفاصيل المنتج/المورد/الدفعات/الاتجاهات واحتياط صيغ الخلايا.
- [x] إنشاء QR محلي لصيغة TLV/Base64 من الوسوم 1–5 مع عرض وسومه؛ واجهة توضح صراحة أنه ليس Phase 2 ولا تقديمًا رسميًا.
- [x] اختبارات تكامل للشراء، المتوسط المرجّح، أثر المخزون، التوازن، الدفع الجزئي، idempotency، تداخل القواعد الضريبية، ووسوم QR.

## حدود معلومة يجب إكمالها قبل تشغيل منشأة على الويب

- [ ] نشر API وقاعدة بيانات PostgreSQL آمنين، ربط الدومين وHTTPS، إعداد السر/المستخدم/الصلاحيات والتخزين والنسخ الاحتياطي والاستعادة. الموقع الحالي على Pages معاينة ثابتة فقط.
- [ ] أوامر شراء، عروض أسعار، اعتماد شراء، استلام جزئي/متعدد الشحنات، مرتجعات وإشعار دائن وتسوية مورد وحد الائتمان.
- [ ] دفعات لاحقة لفواتير العملاء، تواريخ استحقاق/شروط دفع للعملاء، إشعارات دائنة/مرتجعات البيع والتسويات.
- [ ] مصروفات وأصول وتسويات بنكية وإغلاق فترات وورديات، عكس قيد مُصرّح به، ومراكز تكلفة/ميزانيات.
- [ ] استيراد/ترحيل أرصدة افتتاحية وتاريخ فواتير معتمدة بمراجعة المحاسب، لا توليد قيود تاريخية تخمينية.
- [ ] عزل شركة/فرع/مستودع كامل وصلاحيات سجل/مستخدم، وتدقيق أمني واختبارات تزامن وضغط ونسخ/استعادة على منصة الإنتاج.
- [ ] ZATCA Phase 2: XML UBL مطابق للإصدار الحالي، onboarding/CSID، ختم وتوقيع وسلسلة تجزئة وTLV 6–9 الصحيحة، الإبلاغ للمبسطة والتخليص للقياسية، التحقق بآخر SDK الرسمي ثم Sandbox لحساب المكلف. لا يُفعّل الإنتاج قبل إتمام ذلك واعتماد الإجراء مع مختص.

> الأدوات الإدارية، التقارير التقديرية والـQR المحلي لا تحل محل مراجعة محاسب أو محامٍ أو مواصفات زاتكا الرسمية.
