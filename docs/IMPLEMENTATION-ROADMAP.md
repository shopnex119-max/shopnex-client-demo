# SHOPNEX — خارطة تنفيذ وتسليم

**الحالة:** مصدر النسخة **0.3.0** مدمج في `main` عبر PR #2، ونُشر على [GitHub Pages](https://shopnex119-max.github.io/shopnex.test/). Pages يعرض معاينة ثابتة تفاعلية ببيانات توضيحية فقط؛ لا يتصل بقاعدة API سحابية ولا يحفظ معاملات الزوار. تعمل واجهات API الجديدة عند تشغيل التطبيق المحلي مع قاعدة بياناته.

## ما أُنجز في 0.3.0

1. **المشتريات:** موردون وفواتير مورد ببنود الخادم والخصم والضريبة، استلام كامل للمخزون والدفعات الجزئية/الكاملة ورصيد المورد.
2. **التكلفة والمخزون:** حركة قابلة للتتبع وتكلفة مرجحة مخزنة عند الاستلام، ولقطات مالية للفاتورة؛ يستخدم البيع التكلفة المسجلة لحساب تكلفة البضاعة.
3. **المحاسبة:** دليل أساسي وقيود مزدوجة متوازنة للبيع والشراء والدفع والرصيد الافتتاحي، منع تكرار مصدر القيد، وميزان مراجعة وأستاذ وذمم.
4. **الضريبة:** تصنيف وقواعد VAT مؤرخة وإصدارات/لقطات على البنود، تحقق التداخل وسبب الإعفاء عند اشتراطه.
5. **التقارير:** فترة بتوقيت الرياض، مبيعات ومشتريات ومدفوعات وذمم وضريبة تقديرية ومخزون وتكلفة وهامش إجمالي وتحليل منتجات/موردين واتجاهات يومية وتصدير CSV.
6. **زاتكا:** QR محلي لوسوم TLV الأساسية 1–5، مع عرض القيم وتحذير ظاهر؛ لا اتصال أو ختم أو إبلاغ رسمي.
7. **الواجهة:** شاشات RTL/LTR للمشتريات والمحاسبة والتحليلات وQR، حالة معاينة ظاهرة للموقع العام، وتقسيم حزم لتحسين تحميل الصفحة.

## التحقق المنشور

- GitHub CI فحوص API والواجهة ناجحة، وGitHub Pages نشر بنجاح بعد دمج #2.
- 16 اختبار خلفية ناجح؛ TypeScript/build ناجحان بلا تحذير لحجم الحزمة الأساسية.
- ترحيل Alembic ناجح على SQLite جديدة وعلى قاعدة سابقة محشوة بفاتورة وبند ودفعة وحركة مخزون؛ جرى التحقق من بقاء البيانات القديمة.
- اختُبرت واجهة المعاينة المنشورة HTTP 200 وفُحصت حزمها وتأكد وجود نصوص صفحات المشتريات والمحاسبة والتحليلات وحدود Phase 2.

## ضوابط الحساب

- الخادم وقاعدة البيانات هما مرجع السعر والخصم والضريبة والمخزون؛ لا يعتمد الإجمالي المرسل من المتصفح. تستخدم الأموال في الخادم `Decimal` وتقريب نصف لأعلى؛ تستخدم معاينة الواجهة قيم هللات صحيحة.
- التقارير وVAT والهامش تقديرية من السجلات المتاحة، ولا تحل محل إقرار أو محاسب. لا تُنشأ بنود/دفعات/تكلفة أو قيود تاريخية بأثر رجعي إذا لم تكن محفوظة.
